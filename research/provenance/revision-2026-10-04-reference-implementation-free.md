# Revision — the reference root frees its implementation

*2026-10-04, hours after the portable-reference-root fix and during the
same keyholder-directed errand ("make the CI green"). The gate caught
the second defect in the twentieth layer the same day the layer
existed: its root was implementation-sensitive.*

    old root  af4962c3d6ea89ee681b6423b0725123371c4ba37ca1dab5775472a64998cfb9
    new root  3e7dc82769cb3caa43cc7fa53d9935179d9315c32a6707d6215b3a19d69f4ed5

    reference   e0471a90…  (modules pinned as inputs — implementation inside the root)
            ->  3a2aae1f…  (modules generated — check, vectors, and recipe only)

## What the gate caught

A one-line lint fix in `src/reticuli/reuse.py` (`raise ... from None`)
moved the reference layer's root, and `self_check`'s lockfile refused
the full gate. The lockfile's first sentence is the doctrine: a layer's
root must hold when its implementation changes and move only when a
criterion does. The first reference design violated it — the layer's
room staged all thirty-seven modules as pinned INPUTS, so every
implementation byte sat inside the root. Any future edit anywhere in
`src/` would have churned the lockfile forever.

## The fix

`scripts/selfclaim.py` now stages the reference room's modules as
GENERATED steps — outside the root, exactly as every other layer
carries them. The kernel's own promise does the rest: generated bytes
never enter a root, only the recipe naming them does. The reference
root now covers `vectors_check`, the eighty-one conformance vectors,
and the recipe — the criterion, not the candidate. The lockfile entry
records all three values and both stories.

## The pattern

Twice in one day, the twentieth layer's identity was wrong in a way
only contact could show: CI (the first other machine) caught the
readdir-order dependence, and the gate (the first implementation edit)
caught the input/generated misclassification. Both defects were in the
newest layer; the nineteen older ones held through both. New criteria
are exactly where soundness defects live, and the instruments found
each within hours — which is the discovery loop doing its job on its
own newest part.
