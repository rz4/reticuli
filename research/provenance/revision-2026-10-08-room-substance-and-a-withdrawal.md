## Landed — the room pin checks substance, not presentation

Bundle 9's format-4 room fixture asserted the materialized room recipe
lists its steps in CANONICAL ORDER. That over-reaches: at format 4
step order is authoring form, re-deriving the identical root, so the
assertion refused a conforming kernel that materializes an honest,
guidance-free room in FILE order (the r11 codex tree, caught by the
outside-re-earn kit's own smoke test). `build_check` now compares the
room's steps as a SET — right steps, any order — which still refuses
the r12 defect outright (JSON in the file fails the TOML parse; wrong
content fails the set) while admitting every valid materialization.
The kill-bound lesson a third time: relax an over-strict pin to the
property that actually judges, without reopening the gap it closed.

## NOT landed — the deep-audit dedup-key pin, withdrawn on falsification

The keyholder signed `pin-the-deep-audit-dedup-key` on the strength of
the r13 diagnosis: that r13's deep audit deduped by component name
where the original dedups by root, miscounting the chain. Before
implementing, the mechanism was measured directly — and falsified.
r13's `audit_deep` on an r13-built chain returns the correct eighteen
layers, all distinct names, ok=True; the chain has no duplicate names,
so name-dedup and root-dedup cannot differ on it. The pin would have
moved a root to fix a non-bug.

The true seam is unsettled: r13's deep audit is correct on its own
chain, CRASHES on the original-built chain (a nested-package staging
path, `_kernel/__init__.py`), and the substituted gate failed a
layer-count assertion — three behaviours on three inputs, not yet one
mechanism. It is now an OPEN register item to be isolated by a clean
reproduction before any criterion encodes it. r13's verdict (not
qualifying) is unaffected; only the fix is deferred.

This is the session's second averted mis-pin (the first: a stale
diagnostic path that invented a format-3 finding). Both were caught by
the same rule — measure the mechanism before pinning it — which is the
rule this whole project turns on, here turned on its own maintainer's
diagnosis rather than on a regrown tree's. A signature authorizes an
intent; it does not make a wrong diagnosis right, and the honest
response to "I signed, keep working" was to not pin the thing signed.
