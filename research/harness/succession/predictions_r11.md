# Predictions for succession r11 — the new trial 1

*2026-10-07. Root frozen at bundle 8's reseal. Written before any r11
room opens. The count reset to zero when the glob and vocabulary pins
were adopted, so this is trial 1 of a fresh set — the first set whose
boundary has been sampled by BOTH families.*

## What changed, and what it means for this run

Trial 2 showed the boundary was prior-shaped: five codex generations
drained the codex prior's divergences, and one claude generation found
a load-bearing seam in a place codex never touched. Both pins from
that run have landed. So r11 (codex again) runs against a boundary
hardened by both families for the first time.

## The predictions

- **P1. All twenty layers grow**, first attempt, as in r9 and r10.
- **P2. Identity passes.** The substituted full gate re-earns
  `REPO_OK` inside the hour, as it did at r8 and r9. The glob pin is
  not a hazard for a codex tree — codex packs already expanded both
  sides — so this is a repeat, not a new feat.
- **P3. The recursive step passes** and the bootstrap holds end to end
  (version, verify, refuse, gen-2, audit_repo), as both r9 and r10
  managed.
- **P4. Held-out tests**: 103/103.
- **P5. A clean matrix row**, and this time it means more than it did
  for r9: the verdict word for identity damage is pinned now, so a
  clean row can no longer hide that particular coin flip.
- **P6. No halo.** The pair map lands in the codex band (449–485
  divergent, 235–250 consumed) rather than the claude profile
  (564/197) — the two families' divergence signatures are now a
  measured, repeatable thing, and a codex tree landing in the claude
  band would itself be a finding.

## The honest expectation

A codex tree at a boundary whose only new pins are ones codex already
satisfied should qualify. The informative outcome would be a NEW seam
— and after ten generations, any new seam is most likely to come from
somewhere no instrument has yet pointed: the precedence question just
registered (damage versus failing gate), the refusal-diagnostics seam,
or something off the trial path entirely.

## The set this begins

If r11 qualifies it is **1 of 3** again. Trial 2 should then be claude
at this same frozen root — the symmetric test of whether the glob pin
actually closed what it was written for — and trial 3 either family,
with the outside-machine condition riding on one of them.
